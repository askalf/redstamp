# Framework coverage

> redstamp's 24 detection families mapped onto the frameworks security teams already use — **OWASP Top 10 for LLM Apps (2025)**, **OWASP Agentic AI Threats**, **MITRE ATT&CK**, **MITRE ATLAS**, and **NIST AI RMF** — with every coverage claim backed by a measured recall number from the arena corpus (`corpus.json`, 298 samples).

Generated by `node arena/frameworks.mjs` — never hand-edited. Recall figures use the same `decide()` and posture as the arena, so they match [RESULTS.md](RESULTS.md).

## Headline

- **OWASP LLM Top 10 (2025):** 4 covered, 3 partial, 3 out of scope — the out-of-scope rows (model poisoning, embeddings, misinformation) are a *different layer*, not a gap.
- **OWASP Agentic (T1–T15):** 4 covered, 4 partial — spanning Tool Misuse, Privilege Compromise, RCE, and Repudiation.
- **Measured:** **168/168** malicious samples hard-blocked (**100%** recall) and **43/44** risky samples escalated for review, at **100%** precision (0/86 benign false-positives). The one risky under-gate is the documented `risky-infra` curl-download-to-disk case — a fetch, not an egress, allowed by design.

Coverage without a measured number is a claim; every row below carries both.

**Coverage: 4 covered · 3 partial · 3 out of scope** — of 10.

_Scope reasons (honest, per row):_
- **LLM01 Prompt Injection** — ✅ covered. Screens prompt-injection text in untrusted skill/tool descriptions and tool results; neutralises injected instructions before they reach the agent.
- **LLM02 Sensitive Information Disclosure** — ✅ covered. Blocks credential/secret egress and cloud-metadata SSRF; flags secret reads.
- **LLM03 Supply Chain** — 🟡 partial. Catches supply-chain-shaped RCE (git ext::/hooks) and poisoned-skill text; full dependency/provenance pinning is redstamp's sibling truecopy, not this classifier.
- **LLM04 Data and Model Poisoning** — ⬜ out of scope. Training-data / model poisoning is out of scope for a runtime tool-call firewall (runtime instruction-poisoning is covered under LLM01).
- **LLM05 Improper Output Handling** — ✅ covered. The LLM's output IS the tool call — redstamp validates and blocks the downstream action, and neutralises injected tool-result output.
- **LLM06 Excessive Agency** — ✅ covered. Core thesis: constrains agent agency by blocking destructive, persistence, privilege, and defense-evasion actions and escalating dual-use ones.
- **LLM07 System Prompt Leakage** — 🟡 partial. Does not protect system-prompt text itself, but blocks egress of the secrets a leaked prompt would try to carry (via LLM02 families).
- **LLM08 Vector and Embedding Weaknesses** — ⬜ out of scope. RAG / vector-store / embedding weaknesses are a different layer; redstamp does not inspect retrieval.
- **LLM09 Misinformation** — ⬜ out of scope. Misinformation / hallucination content is not a tool-call action; out of scope.
- **LLM10 Unbounded Consumption** — 🟡 partial. Escalates some resource-heavy infra actions, but redstamp is not a rate/cost limiter — unbounded consumption is only partially addressed.

**Coverage: 4 covered · 4 partial · 7 out of scope** — of 15.

_Scope reasons (honest, per row):_
- **T1 Memory Poisoning** — ⬜ out of scope. Agent memory stores are not inspected; runtime instruction poisoning is covered under T6/LLM01.
- **T2 Tool Misuse** — ✅ covered. Tool misuse is the primary axis — every action is classified before execution.
- **T3 Privilege Compromise** — ✅ covered. Blocks privilege escalation, container escape, kernel-module load, and defense disabling.
- **T4 Resource Overload** — 🟡 partial. Blocks destructive availability attacks; not a resource/rate limiter for compute overload.
- **T5 Cascading Hallucination Attacks** — ⬜ out of scope. Cascading hallucination is a reasoning-chain failure, not a tool-call action.
- **T6 Intent Breaking & Goal Manipulation** — 🟡 partial. Indirect injection that redirects intent is screened at the injected-text and resulting-action level.
- **T7 Misaligned & Deceptive Behaviors** — ⬜ out of scope. Deceptive-behavior detection needs trajectory/goal modelling redstamp does not do.
- **T8 Repudiation & Untraceability** — ✅ covered. Covered by the tamper-evident hash-chained audit log (verifyAuditFile / checkpoint), not the action classifier — every allowed/blocked verdict is recorded in an append-only, verifiable chain.
- **T9 Identity Spoofing & Impersonation** — ⬜ out of scope. Agent identity/impersonation is an auth-layer concern, out of scope.
- **T10 Overwhelming Human-in-the-Loop** — 🟡 partial. Deterministic verdicts and an approve tier reduce human-review flooding, but the escalation-volume design is the operator's.
- **T11 Unexpected RCE and Code Attacks** — ✅ covered. RCE via download cradles, pipe-to-interpreter, reverse shells, git-RCE, and obfuscated exec is core coverage.
- **T12 Agent Communication Poisoning** — 🟡 partial. The MCP proxy scans inter-tool results/skill text for poisoning (injection-skill family).
- **T13 Rogue Agents in Multi-Agent Systems** — ⬜ out of scope. Multi-agent rogue-agent detection is out of scope for a single action firewall.
- **T14 Human Attacks on Multi-Agent Systems** — ⬜ out of scope. Multi-agent human-attack surface is out of scope.
- **T15 Human Manipulation** — ⬜ out of scope. Human manipulation is a social/UX concern, not a tool-call action.

## NIST AI RMF (function alignment)

redstamp is a **MEASURE**-and-**MANAGE** control: it measures the risk of each agent action against a policy and manages the response (allow / escalate / block), with the audit log serving **GOVERN** accountability and the poisoned-skill scan serving **MAP** context.

## Honest scope

This matrix is a **map, not a trophy**. redstamp is one layer — the action firewall between an agent and its tools. Rows marked *out of scope* (training-data poisoning, embeddings, misinformation, multi-agent social threats) are addressed by other layers (retrieval guards, provenance pinning, alignment training), not by this classifier, and saying so is the point. The families it does cover are backed by an open, reproducible corpus and the same `decide()` the product ships.
